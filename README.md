# ChatOps DevOps Bot

A ChatOps-based Telegram bot to manage Docker containers remotely.

## Features
- Deploy, monitor, fetch logs, and rollback containers via Telegram commands
- Role-Based Access Control (Admin, Developer, Viewer)
- Real-time container stats and health monitoring using Docker SDK
- Automated failure notifications
- Deployed using Docker Compose with environment-based configuration

## Tech Stack
- Python
- Docker & Docker Compose
- Telegram Bot API

## Use Case
Enables DevOps teams to perform operational tasks securely without direct server access.
